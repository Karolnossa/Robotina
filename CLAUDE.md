# Mapa: dónde está cada cosa
- proyectos/: una carpeta por proyecto.
- conocimiento/personas/: un perfil por persona.
- reuniones/: notas y resúmenes de reuniones.
- pendientes/: tareas y seguimientos.

Antes de cada tarea:
- Escribir a alguien → lee conocimiento/personas/[nombre].md
- Tarea de un proyecto → lee primero proyectos/[proyecto]/
- Preparar una reunión → lee las notas de la anterior en reuniones/
- Al empezar el día → revisa pendientes/
